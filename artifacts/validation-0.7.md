# Harbor Terminal 0.7 验证记录

## 功能和协议

本轮实现SSH会话策略、主机公钥/CA管理、加密身份工具、独立用户证书、压缩/重协商和协商元数据。未实现条目由85降到73；41项已验证子集、65项部分实现仍保留各自验收缺口。

云端Linux/Python3.12全套304通过、0失败、0跳过，见test-results-0.7.0.xml。新增测试覆盖真实SSH密码/公钥/证书连接及实际协议字段，包含：

- 强制Curve25519、AES128-CTR、SHA2-ETM及RSA主机SHA2-256；RSA用户认证实际签名遵守服务器SHA2-256限制。
- 双方Strict KEX、非Strict服务器认证前拒绝且零密码发送、显式兼容、未知运行库适配失败关闭；KEXINIT前注入合法IGNORE包被拒绝。
- 分别按4096字节及1秒触发实际NEWKEYS，512KiB二进制往返完整；延迟压缩在认证前未启用。
- 主机CA有效/错误principal/过期/未知CA/吊销CA/吊销主机；用户证书有效/错钥/过期/错principal，不回退裸公钥。
- 仅提供旧算法的受控服务器，默认先拒绝，再经显式配置连接；目标与跳板兼容设置、CLI开关、GUI回车取消。
- 加密Ed25519/RSA3072/ECDSA身份认证，错口令、文件创建竞争、回滚保留竞争者、公钥指纹、取消及后台线程关闭。
- OpenSSH超大KDF参数进入解密前拒绝、私钥输入1MiB限制；主机公钥框拒绝私钥，避免库自动提取公钥后误保存。
- 指纹确认必须主动勾选、取消不保存、并发修订冲突；schema4迁移5及XML回读、算法顺序保留、旧算法注入拒绝。

原始畸形SSH包只覆盖超大与截断，以及上述Strict前额外包；没有全协议fuzz或厂商缺陷私有样本。Windows对截断连接可能返回ConnectionResetError，测试仍要求3秒内拒绝并且连接/进程为空。
