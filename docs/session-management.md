# 会话管理、导入与默认模板

0.6使用“文件 → 会话管理…”或Alt+Shift+S打开管理器。按Ctrl/Shift多选，可筛选名称、主机和用户名。操作只改配置，已有连接继续使用自己的参数；导入不会自动连接或发送命令。

## 批量编辑与重命名

选中会话后点“批量编辑”。**只有勾选的字段会修改**；清空可选字段也需勾选。可先填入SSH或Serial默认值，再选择应用字段，最后检查原值/新值预览。参数不合法时整批拒绝，取消不会写入。

“重命名路径”可改会话名称或文件夹前缀，跳板引用随同一次保存更新。允许仅改大小写；与其他名称冲突时拒绝覆盖。删除仍被其他会话引用的跳板时，需明确一并选择依赖会话，不会把它们悄悄改成直连。

## CSV / TSV导入

选择文件后检查格式、编码与列映射。支持UTF-8（含BOM）、GB18030和UTF-16；名称与目标列必须有唯一映射。可先读取全部行，再取消勾选不导入的会话。

```csv
Name,Host,Port,Username,Mode
实验室/核心交换机,192.0.2.10,22,operator,SSH
实验室/控制台,COM3,115200,,Serial
```

仅支持SSH/Serial。CSV引号、中文及合法转义由CSV解析器处理；最多500项、2MiB输入。密码、私钥内容等列默认忽略，未知列需明确映射或忽略。未提供的端口/协议字段不擅自写入，便于“仅合并已提供字段”；新SSH/Serial会话读取时分别使用其内建缺省端口/波特率。

同名冲突可选：

- 仅新增：保留已有会话，跳过冲突项。
- 替换：用导入字段替换整个同名记录。
- 合并：只覆盖导入中明确提供的字段。
- 创建副本：产生唯一名称，批内跳板引用指向相应副本。

大小写歧义或重复名称拒绝导入。最终预览列出新增、修改、删除及每个字段的原/新值；有缺失跳板引用会提示，连接前需补齐。

## XML / JSON导入导出

导出只包含明确选中的会话与白名单字段，支持Harbor原生XML及版本化JSON；可再次导入。它不包含主机公钥库、私钥内容、密码、凭据库或转发模板，XML不是SecureCRT专有格式转换。DTD/entity、嵌套字段、未知字段和重复JSON键均被拒绝。

已核验的known_hosts和私钥文件路径可以随会话保存，文件内容不会一起导出。配置及其路径元数据仍是明文。程序不允许导出覆盖自身管理的会话、默认模板、命令库或显示配置文件。

## 独立协议默认值

“选项 → 默认会话模板…”分别编辑SSH与Serial。模板不保存目标主机、串口设备、密码或跳板引用，仅影响新建连接和切换协议时的初始参数；已有会话保持原值。要应用到已有会话，请在管理器选择范围、填入模板、勾选字段并预览。

## 并发、备份与恢复

本版本各窗口使用OS文件锁及内容修订号。其他窗口在你读取后保存过，或预览期间数据变化时，保存会拒绝覆盖；点“重新载入”后重新编辑。配置文件损坏或版本不支持时不自动重置。

每次替换前保留上次有效的`.bak`。在管理器点“恢复上次有效备份”，检查将恢复的内容；恢复同时核对当前文件与备份的修订号，当前文件另存为`.damaged-…`副本。替换后目录持久化无法确认时显示“结果待确认”，需重新载入核对。

锁只协调遵守同一协议的程序；没有跨文件、跨机器或网络文件系统的完整事务保证。defaults.json独立保存模板；出现损坏时保护原文件，不自动覆盖。

## 当前连接操作

“文件 → 克隆当前连接…”或“重新连接…”载入非秘密参数，重新输入本次凭据后建立独立连接；不会复用原SSH传输。跳板仍按当前保存的引用解析。临时标签名仅改当前标签，不改保存的会话；最近会话列表仍待实现。

活动会话页支持名称/主机/状态筛选、状态计数与多选。选择“选中会话操作”后检查固定范围，可批量断开或锁定/解锁输入。输入锁只防误触，不隐藏输出或验证口令；已启动流程仍继续，自动终端应答保持工作。它不是安全锁或桌面锁。
