# 输入、ASCII文件与串口线路（0.8）

本轮增加输入节流、文本文件收发、串口线路窗口、粘贴变换、Alt Meta与清历史策略。设置位于“会话选项 → 输入 / 发送”，下次连接生效；也可经独立SSH/Serial默认模板及明确勾选的批量字段保存。会话JSON/schema6及Harbor原生XML读取旧版本，路径/参数仍是本机明文，不保存口令。

## 慢速设备发送

字节间隔0–1000ms，行间隔0–30000ms；默认均为0。字节间隔作用于编码后的字节，非Unicode字符或字词。一个CRLF按一次行结束，延迟不改变实际字节；边界分属两次独立输入时分别处理。普通输入、粘贴、流程和ASCII发送使用同一发送器，二进制Hex发送也会受当前会话间隔影响。SFTP独立通道不受影响。

终端协议应答有独立队列，可在输入等待期间优先写出，避免慢速粘贴阻塞DSR等应答。取消流程/文本任务会停止尚未写出的自有数据；已提交给操作系统或SSH缓冲区的内容不能撤回，也不自动重试。输入锁阻止新的手动发送，已启动的任务仍继续。

## ASCII / 文本文件发送

连接到交互SSH或Serial后，打开“传输 → ASCII / 文本文件收发…”。每个窗口固定绑定打开它的会话，切换标签不会改变目标。

1. 选文件、源编码、发送编码及CR/LF/CRLF/保持原样。
2. 点“读取并冻结预览”，核对字节数与内容。最多读取/发送1MiB，每行64KiB；预览显示前8192字节，`␍/␊`标记行尾。
3. 可填每行发送后等待的**字面提示**及1–120秒期限。不使用正则或已有历史提示，也不把出现提示当作远端命令成功。
4. 点“发送预览内容”。发送使用冻结的字节，不重新读取源文件；不隐式追加最后一行换行。

UTF-8（含BOM）、UTF-16、GB18030、Big5、Shift-JIS、Latin-1和ASCII按界面选择转换；不丢弃不能编码的字符。文件含ESC/NUL等终端控制字符时拒绝，这不是二进制传输。ASCII任务与命令流程互斥，期间普通输入拒绝，Ctrl+C取消任务并排队发送中断；全任务上限1小时。

进度/结果中的确认写入字节是本机传输层确认的下限，不是设备执行确认。部分写入明确报告前缀；无法确认结果的I/O中断另标“待确认”，不会把失败内容重新发送。

## 接收为纯文本

在“接收为文本”选择新的文件、文件编码和换行，再点“开始接收”。只采集开始后的RX，使用当前终端编码严格解码，按分片状态过滤终端控制序列，再编码写入文件；不是终端屏幕重建，不执行任何远端序列。

已有文件不覆盖，新文件使用排他创建。写盘线程队列最多1MiB/256项，文件最多8MiB；队列满、编码错误、磁盘错误或达到容量会停止采集并显示错误，终端继续使用。跨分片Unicode和CRLF正确处理；停止时严格完成解码、排空已接受队列并同步文件。

点“停止并落盘”或关闭收发窗口结束采集；断开也关闭写盘线程。停止只表示本地采集结束，没有远端文件结束握手、长度/CRC、重传或续传保证。错误、断开和强制退出可能留下部分文件，必须核对结果。接收文件是明文，可能包含设备回显的数据。

## DTR / RTS及线路状态

Serial会话使用“工具 → 串口线路控制…”。窗口显示DTR/RTS输出设定及CTS/DSR/RI/CD输入，约每500ms刷新。不支持的字段显示“未知”，不会当作低电平正常值。

选择输出线与目标值后需确认，回车默认取消。RTS/CTS流控占用的RTS、DSR/DTR流控占用的DTR不能手动设置，传输层也会拒绝；输入锁和断开时不可操作。改变DTR/RTS可能复位设备，打开串口时驱动也可能改变这些线。显示的是驱动报告，不保证实体电压或接线正确。Linux PTY不支持部分线路，不能当实体COM通过。

## 粘贴、路径与Alt

普通粘贴默认将换行变CR，远端Bracketed Paste启用时默认用LF并添加边界。可明确选CR/LF/CRLF/保持原样，以及POSIX或PowerShell单引号。多行、引用变换和路径粘贴会先显示可编辑原文及实际发送预览；未编辑时“保持原样”保留原始CR/LF，编辑后使用编辑器中的换行。编辑后的内容仍重新检查控制字符、编码和64KiB上限。

终端右键“粘贴文件路径…”只把所选路径作为文本预览/发送，不读取或执行本地文件。引用方式需与远端Shell一致；未提供CMD引用模式。没有自动添加回车执行。

Alt Meta可选ESC前缀/xterm修饰或只发键盘布局文本。可打印的Ctrl+Alt和Qt GroupSwitch作为AltGr文本保留，输入法提交独立发送。应用已有菜单快捷键仍优先；Windows实际国际键盘与输入法布局矩阵仍待实机验证。

## 清屏与清历史

右键菜单分别提供“清除当前屏幕”和“清除历史”，均为本地显示操作，不发送远端命令。远端ED2只清屏；ED3清历史可配置允许或保留，RIS复位也遵守历史保留策略。保留历史不阻止远端清除当前屏幕或使用备用屏幕；本地明确清历史始终生效。仍为2000行历史，没有百万行能力声明。

测试使用真实本地SSH、Linux PTY及受控串口驱动替身，并执行Windows原生/实际EXE检查；实体USB适配器线路和慢速真实设备需按HARDWARE-TESTING.md另行验收，不能由替身或枚举结果推断。
