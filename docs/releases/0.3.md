# 0.3：SFTP、日志与串口Hex

## 可用流程

- SFTP复用已核验主机密钥、已认证的SSH连接。目录浏览、单文件上传/下载、进度、取消与失败反馈已接入独立窗口；不重新询问认证，也不阻塞终端收发。
- 上传先用独占临时文件接收，再回读SHA-256校验。下载先写本地临时文件、fsync并回读校验。明确授权覆盖后才替换目标；不采用先删除目标再改名。
- 默认禁止覆盖。上传新目标的安全提交需要服务器支持hardlink；覆盖需要POSIX rename。缺少能力时报告不支持，不做不安全降级。上传文件以0600创建，覆盖会更换inode/所有者/权限等元数据，不用于保持原目标属性的更新。
- 提交回复丢失显示“结果未知”，不自动重传。已确认提交后才收到取消，报告完成；提交前取消清理暂存，保留原目标。清理未确认时有单独提示。
- 日志显式开启，默认仅RX；用户可另选TX。原始字节使用base64 JSONL，文本使用增量解码后的分块JSONL，控制字符被JSON转义。暂停/继续保留同一文件，并用标记划清接收间隙。
- 日志使用独立磁盘线程、有界队列、独占新文件、单段大小与段数限制；失败/队列满停止日志，不阻塞终端。默认10MiB×5段；无自动删除历史日志。
- 串口Hex按方向、UTC时间与字节偏移观察RX/TX，32KiB/256条记录上限；显示ASCII不解释转义。发送十六进制原始字节，不附加换行，不自动重发。工具固定绑定打开它的会话。
- 后台状态、文件结果与设备枚举通过Qt主线程槽更新界面；进度使用覆盖式快照，避免每数据块产生无界GUI事件。

## 证据

126项测试通过，含原有测试。新增真实本地SSH/SFTP服务：二进制和中文路径往返、哈希回读、原目标保护、空文件、源改变、远端读回损坏、取消/断线、原子提交不支持、提交回复丢失和已提交后的取消。

整窗/PTY测试验证SFTP复用认证、终端仍可收发、文件错误不结束SSH、标签切换不改Hex目标、Hex真实原始字节收发、日志I/O失败不影响串口、暂停/继续不重开文件与断开标记去重。

## 明确限制

只做单文件，不支持目录递归、断点续传、拖放、SFTP独立登录、远程改名删除、所有者/权限保留。目录最多2000项/2MiB名称；单文件上限1TiB。硬链接/原子替换能力与文件系统限制会导致安全失败。

日志是JSONL接收分块记录，不是渲染后的屏幕录像或传统纯文本逐行日志；没有跨日轮转、模板、自动启动或通用脱敏。接收输出也可能含敏感数据；TX需另行启用。日志正常关闭会排空队列，阻塞的底层磁盘调用无法用Python强制终止；关闭等待最多5秒后提示。

Hex按串口读取分块，不推断设备消息边界；TX表示本地写入报告，不是设备执行确认。没有Hex/ASCII联动选区。
