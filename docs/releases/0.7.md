# Harbor Terminal 0.7.0

本轮推进SSH安全、身份与主机信任。183项累计能力中，未实现由85降为73；现有41项已验证子集、65项部分实现、1项依赖未验证、1项仅关闭策略、2项安全差异。子集测试不代表SecureCRT 9.7.4全功能等价。

## 可用功能

- 会话级KEX/cipher/MAC/主机及用户签名顺序、算法勾选与排序；按实际运行库筛选现代默认值，没有共同算法就失败。
- 默认在认证前要求Strict KEX，旧服务器需显式兼容；旧算法另需逐项选择，许可本身不改变默认提议。GUI显示目标及跳板范围，回车默认取消；批处理额外开关。
- 按字节/时间重协商、认证后压缩；实际协商元数据窗口及JSON导出，公钥格式与主机签名算法分开显示。
- 主机密钥管理：SHA256指纹、known_hosts导入/导出/删除、别名/非默认端口/散列主机匹配、主机CA与吊销。更改需核对指纹，预览期间变更则拒绝覆盖。
- 后台生成与检查Ed25519/RSA/ECDSA身份，默认bcrypt加密OpenSSH，不覆盖已有密钥；常见私钥误粘贴到主机公钥框会清除。
- 私钥和用户证书可分开选择，检查类型/匹配/有效期，错误证书不退回裸公钥；会话schema5兼容读取1–4。

## 协议与界面证据

真实SSH测试覆盖选定算法、RSA-SHA2实际签名、Strict/非Strict及认证前拒绝、KEXINIT前额外包注入、字节/时间触发NEWKEYS、512KiB二进制完整往返、延迟压缩，以及主机/用户证书错误principal、过期、错钥和吊销。畸形/超大/截断包仅为有限故障注入，不是完整协议fuzz。

Windows首轮原生测试发现兼容确认按钮被Qt原生焦点切回确认，已禁止其自动默认并把焦点固定在取消，增加实际回车取消检查。截断SSH测试同时接受Windows的连接重置和协议错误；仍要求3秒内拒绝且无有效连接，不接受超时通过。初轮失败证据保留在ci-0.7-initial。

## 仍有的限制

Windows Server2025的原生检查不能替代用户Windows10/11、USB串口驱动、实体COM、IME、多显示器、Agent或SecureCRT同机对照。Windows包为未签名开发包，需完整解压，附硬件工具和同机测试规程，无MSI/自动更新。

Strict KEX元数据适配器固定AsyncSSH2.24.1；未知版本在强制模式下拒绝认证。密钥文件依赖目录ACL与同卷硬链接，不是DPAPI/凭据库。RSA证书算法完整矩阵、硬件密钥、FIPS、PPK转换、X.509、完整诊断追踪及通用脚本仍未完成。

环境发布只保存文件，不保留测试进程。旧0.5/0.6最后报告的PID均已不存在；快照另存并标记。0.7长测独立计时，running/interrupted不算72小时通过，不能与旧版累计。没有证据证明整体优于SecureCRT的安全性或稳定性。
