# 0.4.1：参照SecureCRT 9.7重做界面与字体

参考官方[9.7 Windows界面](https://www.vandyke.com/images/screenshots/securecrt/SCRT_9.7_Windows_SessionConfiguration.png)、[PowerShell布局](https://www.vandyke.com/images/screenshots/securecrt/SCRT_9.7_Windows_PowerShell.png)与[活动会话面板](https://www.vandyke.com/images/screenshots/securecrt/ActiveSessionsManager.png)。未复制品牌、资源或代码，也不宣称不同Windows缩放比例下逐像素相同。

## 桌面布局

菜单、16px图标工具栏与主机输入在顶部，左侧为可停靠的会话管理器/活动会话；窄标签只显示名称，以图标区分连接状态，完整状态放入提示和底部状态栏。终端成为主窗口主体，不再被多行连接表单占据。

SSH/串口参数移入快速连接弹窗，Alt+Q打开；保存会话双击后载入并打开弹窗。会话选项改为左侧分类、右侧设置页。菜单与工具栏接入实际已有的连接、SFTP、日志、Hex、隧道与查找操作。未实现的脚本/广播等能力没有增加空按钮。

活动面板列出每个会话的状态，双击切换到对应标签。它尚无过滤、批量断开和锁定功能。

## 字体与配色

Windows界面优先Segoe UI 9pt，终端优先Consolas 11pt。按可用字体回退，不下载或打包Windows字体；本轮云端截图使用Noto Sans CJK SC / Liberation Mono。

终端保留字体实际字宽，减少取整导致的额外字距；统一行高与基线，支持宽字符和字体变化后的PTY尺寸更新。聚焦时使用块光标，未聚焦时使用轮廓。

全局字体/字号通过“选项 → 终端字体”选择，更新已有及新标签。界面支持经典浅色/深色，终端支持黑底/浅色/深蓝；偏好单独保存到appearance.ini，避免混入会话和认证数据。Ctrl+滚轮仅临时缩放当前标签。

查找栏按需打开并可关闭；底部显示协议、编码、行列和日志/隧道状态。SFTP、日志、Hex、隧道工具继承桌面配色，Hex使用等宽字体。工具栏图标自行绘制，提供1x/2x资源。

全量150项测试通过，包括新快速连接弹窗到真实SSH服务的登录、Ctrl+C/D/S原样收发、查找焦点、取消清除口令、实际字体对话框选择/取消、字体/配色切换保持屏幕内容，以及行列同步和独立偏好保存。见[验证记录](../../artifacts/validation-0.4.1.md)。

Windows原生字体、IME、多显示器125%–300%DPI和实体COM仍待实机验收；独立会话配色、可配置行距、完整主题跟随系统尚未实现。本次是界面改造，完整产品能力与安全/稳定性对照边界见原有矩阵。
