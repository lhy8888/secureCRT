# Harbor Terminal 0.8.0

本轮补充慢速设备输入、ASCII文本收发和串口线路操作。183项累计能力中，未实现从73降至67；45项已验证子集、67项部分实现、1项依赖未验证、1项仅关闭策略、2项安全差异。没有SecureCRT 9.7.4整体等价性结论。

## 本轮功能

- 逐编码字节和逐行延迟，CRLF按一行。终端协议应答在间隔中优先，取消停止自有未发送数据，已写出内容不撤回、不重试。
- ASCII/文本文件发送支持源/目标编码、换行、冻结预览、逐行新RX字面提示、进度和取消；接收可过滤控制序列、严格转码及规范换行写入排他新文件。
- 串口线路窗口显示DTR/RTS设定及CTS/DSR/RI/CD输入，未知显示未知；改变输出需确认，自动硬件流控占用线拒绝手动覆盖。
- 粘贴换行、POSIX/PowerShell单引号、文件路径文本粘贴与实际发送预览；不读取/执行所选路径，不隐式追加回车。
- Alt Meta/AltGr/IME独立处理；本地清屏/清历史及远端ED3/RIS历史保留策略。
- schema6读取旧1–5，输入与安全字段进入默认模板及批量编辑；修正0.7批量字段选择遗漏，以及输入模板“自动”误用认证标签的问题。
