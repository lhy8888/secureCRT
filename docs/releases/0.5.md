# Harbor Terminal 0.5.0

0.5补齐认证与命令工作流，首次交付实际Windows x64便携包及实体串口测试工具。[验证记录](../../artifacts/validation-0.5.md)区分本地测试、Windows CI、用户硬件与长期运行。

## 认证与连接

键盘交互认证实现真实多轮多提示应答，保留LF与echo位；跳板和目标分别标识，非阻塞Qt窗口掩码输入。90秒提示期限、最多8轮/16个提示和32KiB文本预算，受180秒总认证期限限制。回复绑定当前请求且只接收一次，取消不回退密码。五种顺序预设：默认公钥优先、密码优先、交互优先、仅公钥、仅交互。

修复默认密钥选择：向AsyncSSH传入client_keys=None会禁用公钥，现未显式选择时省略该参数，实际默认密钥签名已验证。禁用隐式OpenSSH配置继承，不执行未在UI显示的ProxyCommand。未验证Windows Agent、硬件密钥和证书。

配置v4可读取v1–v3，增加认证预设和仅通道模式。仅通道模式不打开Shell/PTY；真实SFTP验证且远端进程数为零，终端发送、BREAK、命令流程被拒绝。

## 命令与流程

Alt+M打开多行命令面板、50条内存历史、独立明文命令库、筛选/增删与按钮栏。勾选目标后可编辑预览，使用会话UUID固定目标；切标签或新增连接不会静默改发送对象。置顶按钮仅当前会话。结果只确认入队，不推断设备执行成功。

独立有界接收流支持增量解码、控制串过滤、跨分片字面匹配、候选序号与匹配前文本捕获，不消费GUI显示缓冲。游标被覆盖立即失败；取消/断开释放等待者。每会话一个JSON流程，只允许send/wait/delay，最多64步、单步等待120秒、600秒总时限和64KiB捕获。取消清理尚未发送的数据，不重放，已发送内容不能撤回。

示例（只用于你确认支持这些命令的实验设备）：

```json
{"version":1,"steps":[
  {"action":"send","text":"show version","newline":true},
  {"action":"wait","patterns":["#",">"],"timeout":15}
]}
```

CLI支持目标解析、GUI预填、保存会话选择、显式无界面SSH/Serial流程及新JSON结果，严格校验主机，不接受命令行/URI口令：

```powershell
.\HarborTerminal.exe admin@host.example --known-hosts C:\Keys\known_hosts
.\HarborTerminal.exe admin@host.example --identity-file C:\Keys\id_ed25519 --known-hosts C:\Keys\known_hosts --run-flow .\flow.json --output .\new-result.json
```

CLI没有交互MFA/加密密钥口令输入。串口用--serial-port COM3 --baudrate 115200。流程/命令库/捕获报告为显式保存的明文，不能存秘密，也不提供Python/eval、crt对象或凭据引用。

## Windows与转发修复

首次Windows测试复现本地监听重复绑定：AsyncSSH的SO_REUSEADDR在Windows不能提供所需独占语义。改由自有回环socket在绑定前设置SO_EXCLUSIVEADDRUSE，真实第二次绑定被拒绝。自有SOCKS5处理IPv4/域名/IPv6地址解析，拒绝不支持的认证/命令，限制握手时长和每会话64个本地转发流。半关闭与取消有回归；IPv6实际互通、远程服务端绑定策略和长期并发仍待验收。

Python3.13+的asyncio.Server.wait_closed会等待已有流。停止监听避免因此挂住，保留既有流收发，断开SSH才完整关闭；有实际回归。

CI使用Windows原生Qt平台后确认Segoe UI/Consolas，启动冻结EXE执行加密SSH/私钥、SFTP、严格主机拒绝、MFA、转发和批处理，验证100/125/150/200/300%启动及选项/字体对话框。小屏幕裁切不构成完整DPI通过。发布运行时使用官方Windows Python3.14.10，保留3.12/3.14双平台源码测试。

## 硬件与长期验证

包内Test-HarborHardware.ps1提供清单、显式二进制回环、只读拔插及72小时入口，只写本地报告；回环必须先准备TX/RX。序列号重复拒绝身份判断，无序列号仅按端口名观察。尚未取得用户实体报告。

Measure-HarborComparison.ps1记录本机进程资源，不读取终端正文/密码、不自动连接设备。completed仅表示采样到时限，不代表稳定性通过。同机规程随包提供，尚无SecureCRT实测结果。

旧基线运行4162.57秒、20428循环、0错误后主动中止，独立报告保留；没有完成72小时。最新代码重新启动259200秒测试，记录全部Python源文件哈希并加入自动化流程收发；只有实际到时且无错误才能通过，不能与旧基线时间相加。环境发布/迁移后不能假设进程继续。
