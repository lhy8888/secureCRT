# 0.2：终端核心与串口工作流

## 已交付

将原纯文本屏幕改成独立的终端模型、字格绘制、按键编码和连接所有者。Qt显示可见行及字符属性，主/备用屏幕分离；接收背压不会阻塞发送任务。连接中的取消和关闭窗口不再依赖等到登录超时后重试关闭。

新增串口参数/枚举、连接设置中的私钥与口令、可编辑多行粘贴、Bracketed Paste、字面查找/高亮、缩放和基础层级会话树。配置v2兼容读取v1；凭据字段继续拒绝保存。

本项目修复了实看截图发现的垂直缩小时首行和提示行被无条件删除的问题；仅在光标超出新高度时滚动，移出行进入历史。横向重排尚未实现。解析层对保存光标堆栈、组合字符和高开销重复控制序列增加边界。
